3. World files from other people
--------------------------------------------------------------------------------

A .world file is a document written by whoever created it. The application
treats files it did not write as untrusted and checks them before opening: note
content cannot run HTML or JavaScript, embedded images cannot be written outside
the assets folder, and malformed data is repaired or refused rather than
allowed to lock the application up.

No such check is ever complete. Open files from people you trust, and treat one
from an unknown source with the same caution you would give any downloaded
document.

The checks themselves are written up in docs/security-gates.md in the source
repository, if you would rather read them than take this on trust.
